# 智能澄清機制測試說明

## 概述

本測試程式用於驗證改進後的智能澄清機制，確保系統能夠：
1. 正確理解用戶的日常用語
2. 生成適當的智能澄清問題
3. 根據用戶選擇正確映射到相應的查詢意圖
4. 提供友善的幫助信息

## 測試檔案

### 1. `test_smart_clarification.py` - 完整測試程式
- **功能**：全面的測試套件，包含所有功能測試
- **特點**：
  - 詳細的測試案例覆蓋
  - 自動生成測試報告
  - 保存詳細的測試結果到 JSON 檔案
  - 統計測試成功率

### 2. `quick_test_smart_clarification.py` - 快速測試程式
- **功能**：簡化的快速驗證工具
- **特點**：
  - 快速驗證核心功能
  - 即時顯示測試結果
  - 適合開發過程中的快速檢查

## 執行測試

### 快速測試（推薦）
```bash
python quick_test_smart_clarification.py
```

### 完整測試
```bash
python test_smart_clarification.py
```

## 測試內容

### 1. 基本查詢場景測試
測試系統對以下查詢的處理：
- `哪一款筆電比較省電？`
- `哪一款筆電比較適合玩遊戲？`
- `推薦適合辦公的筆電`
- `學生用筆電推薦`
- `設計用筆電哪個好？`

**預期結果**：系統應該識別為 `unknown` 查詢類型，並生成智能澄清問題

### 2. 智能澄清回應處理測試
測試用戶選擇後的意圖映射：
- 遊戲場景 → 958 系列，GPU/CPU 意圖
- 辦公場景 → 819 系列，電池/CPU 意圖
- 學習場景 → 839 系列，電池/CPU 意圖

**預期結果**：正確映射到相應的模型類型和意圖

### 3. 友善幫助信息測試
測試系統生成的幫助信息是否包含預期關鍵詞：
- 比較查詢 → 包含「比較」、「差異」、「推薦」
- 遊戲查詢 → 包含「遊戲」、「電競」、「性能」
- 辦公查詢 → 包含「辦公」、「商務」、「續航」

### 4. 意圖識別測試
測試系統對日常用語的識別：
- `哪個比較快？` → CPU/性能意圖
- `哪個比較省電？` → 電池意圖
- `哪個比較輕？` → 便攜性意圖

### 5. 端到端場景測試
模擬完整的用戶交互流程：
1. 用戶發送模糊查詢
2. 系統生成智能澄清問題
3. 用戶選擇選項
4. 系統處理選擇並查詢數據

## 測試結果解讀

### 成功指標
- ✅ 查詢類型正確識別為 `unknown`
- ✅ 成功生成智能澄清問題
- ✅ 正確映射用戶選擇到查詢意圖
- ✅ 幫助信息包含預期關鍵詞
- ✅ 端到端流程正常執行

### 失敗情況
- ❌ 查詢類型不是 `unknown`（系統要求過於嚴格）
- ❌ 未生成智能澄清問題
- ❌ 意圖映射錯誤
- ❌ 幫助信息不包含預期內容
- ❌ 數據查詢失敗

## 常見問題

### Q: 測試失敗怎麼辦？
A: 檢查以下幾點：
1. 確保所有依賴已安裝
2. 檢查資料庫連接
3. 確認配置檔案路徑正確
4. 查看錯誤日誌

### Q: 如何添加新的測試案例？
A: 在相應的測試方法中添加新的測試案例：
```python
{
    "name": "新測試案例",
    "query": "新的查詢",
    "expected_type": "預期結果"
}
```

### Q: 如何修改預期結果？
A: 根據實際需求修改測試案例中的 `expected_*` 欄位
